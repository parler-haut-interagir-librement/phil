# Reference

Every public type of the package, with its role.

| Type | Role |
|---|---|
| `LatexToMathMl` | Converts a LaTeX formula to a `<math>` element of MathML Core. |
| `Exception\LatexMathMlException` | Implemented by every exception of the package. |
| `Exception\InvalidLatex` | A formula that cannot be converted, with the byte offset of the problem. |
