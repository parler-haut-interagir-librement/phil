# Référence

Chaque type public du paquet, avec son rôle.

| Type | Rôle |
|---|---|
| `LatexToMathMl` | Convertit une formule LaTeX en un élément `<math>` de MathML Core. |
| `Exception\LatexMathMlException` | Implémentée par chaque exception du paquet. |
| `Exception\InvalidLatex` | Une formule qui ne peut pas être convertie, avec la position en octets du problème. |
