# Installation

| Requirement | Version | Why |
|---|---|---|
| PHP | 8.5 or later | The floor the library declares and is tested on |
| `ext-mbstring` | any | Messages cut to a length in characters |
| `phil/enums` | ^0.3@dev | `EnumSet`, the sets of services a field accepts |
| `phil/phone` | ^0.1@dev | Reading phone numbers in their country's plan |
| `phil/url` | ^0.1@dev | Reading the services' links |

```sh
composer require phil/instant-messenger
```
