# Installation

| Prérequis | Version | Pourquoi |
|---|---|---|
| PHP | 8.5 ou plus récent | Le plancher que la bibliothèque déclare et sur lequel elle est testée |
| `ext-mbstring` | toutes | Les libellés et les messages sont mesurés et coupés en caractères |

```sh
composer require phil/opening-hours
```
