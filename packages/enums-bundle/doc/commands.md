# Commands

Four commands, registered when `symfony/console` is installed — `phil:enums:check-sets` also needs `doctrine/orm` —,
and `make:enum` with MakerBundle.
The first two read the enums declared under the configured
`paths` ([Configuration](configuration.md)): the finder reads the tokens of each PHP file — the namespace, then each
`enum` declaration — and keeps the enums the autoloader finds, so a file outside the autoloader's map contributes
nothing.

## debug:enums

Without argument, the enums of the paths, with their backing type, their number of cases and whether they are
translatable:

```console
$ bin/console debug:enums
 ------------------------- --------- ------- --------------
  Enum                      Backing   Cases   Translatable
 ------------------------- --------- ------- --------------
  App\Order\OrderStatus     string    4       yes
  App\Security\Permission   int       3       no
 ------------------------- --------- ------- --------------
```

With an enum — its class, or its short name when it names one enum only —, its cases: value, label, description,
groups, weight, and the marks `default` and `deprecated`.

```console
$ bin/console debug:enums Permission
 ------- ------- ------- --------------- --------------- -------- ------------
  Case    Value   Label   Description     Groups          Weight   Marks
 ------- ------- ------- --------------- --------------- -------- ------------
  Read    1       Read                    basic           1        default
  Write   2       Write                   basic, editor   1
  Admin   4       Admin   Every right.                    0        deprecated
 ------- ------- ------- --------------- --------------- -------- ------------
```

It warns about each case that misses a meta property the enum's `#[RequiredMeta]` asks for. With
`--locale=fr`, it lists the label and description keys of a translatable enum that have no translation in that
locale and domain — the keys `translation:extract` would add.

**It fails** — exit code 1 — when the name matches no enum or several, when a case misses required metadata, or
when a key lacks its translation: run it in continuous integration to keep enums labelled and translated.

## phil:enums:typescript

Writes enums as TypeScript, so that a front end shares their values and labels instead of copying them:

```console
$ bin/console phil:enums:typescript --output=assets/enums.ts
$ bin/console phil:enums:typescript 'App\Order\OrderStatus' --locale=fr
```

```ts
// Generated by phil/enums-bundle; do not edit.

export const OrderStatus = {
  PENDING: "pending",
  /** @deprecated */
  ON_HOLD: "on_hold",
} as const;
export type OrderStatus = (typeof OrderStatus)[keyof typeof OrderStatus];
export const OrderStatusLabels: Record<OrderStatus, string> = {
  "pending": "En attente",
  "on_hold": "Suspendue",
};
```

| Argument or option | Meaning |
|---|---|
| `enums` | The enum classes to write; every enum of the paths by default. A class that is not an enum fails. |
| `--output`, `-o` | The file to write; the standard output by default. |
| `--locale` | Translate the labels of translatable enums in this locale; without it, or without a translator, each case's `Label`, or its name. |
| `--check` | Write nothing; fail when the file `--output` names differs from what would be written. For continuous integration. |

- **One constant object, one union type and one label record per enum**, named after its short name; two enums of
  one short name are refused — export them separately.
- **A pure enum** is written by its names.
- **Deprecated cases are kept**, marked `@deprecated`: the front end still reads records that hold them.
- **What the enum declares beside** follows when it has some: `<Enum>Descriptions` for the cases with a
  `Description`, `<Enum>Groups` for its `#[Group]`s, `<Enum>Default` for its `#[DefaultCase]`.

Commit the generated file, or generate it in the front end's build; rerun the command when an enum changes.

## phil:enums:icu

Writes an ICU `select` message over the cases of an enum, to translate a sentence that changes with the case rather
than the case alone:

```console
$ bin/console phil:enums:icu 'App\Order\OrderStatus' --argument=status --locale=fr
{status, select, pending {En attente} paid {Payée} shipped {Expédiée} other {}}
```

Each branch is keyed by the case's value — its name in snake case for a pure enum —, its text the case's label,
translated with `--locale`. Paste it into a catalogue of the `+intl-icu` format, and write each branch's sentence.
Braces and apostrophes in a label are quoted as ICU requires.

A key must be an ICU keyword, which holds no white space and no punctuation: a value such as `in-progress`, `v1.2`
or `a b` would give a message `MessageFormatter` refuses. The command checks that each key holds only letters,
marks, digits and underscores, is not `other` — the branch ICU requires —, and comes once (two pure cases `FooBar`
and `Foo_Bar` share `foo_bar`); otherwise it fails with a message naming the case, and writes nothing. The
`--argument` name is checked the same way. Give such a case a value ICU accepts (`in_progress`).

## phil:enums:check-sets

Reads every stored value of every `EnumSet` column the entities map, and lists those that no longer name cases —
a removed case, a renumbered flag ([Doctrine](doctrine.md)). It fails when it lists any.

## make:enum

With MakerBundle installed, `make:enum` writes a new enum in the application's `Enum\` namespace, with
`AsEnumerableEnumTrait`, `#[Meta(Label::class)]` and a `Label` on each case:

```console
$ bin/console make:enum OrderStatus --case=Pending --case=InTransit --translatable
```

```php
#[Meta(Label::class)]
enum OrderStatus: string implements TranslatableInterface
{
    use AsEnumerableEnumTrait;
    use AsTranslatableEnumTrait;

    #[Label('Pending')]
    case Pending = 'pending';

    #[Label('In transit')]
    case InTransit = 'in_transit';
}
```

| Argument or option | Meaning |
|---|---|
| `name` | The enum's name; asked when missing. |
| `--case` | A case name, repeated for each case; without it, the command asks for them one by one until an empty answer. |
| `--backed` | `string` (the default) — values are the names in snake case —, `int` — 1, 2, 3… —, or `pure`. |
| `--translatable` | Implement `TranslatableInterface` with `AsTranslatableEnumTrait`, the labels as keys. |

A name that is not a PHP identifier, or comes twice, is refused; so are, for a string enum, two names whose words
give the same value (`FooBar` and `Foo_Bar`, `ACTIVE` and `Active`), which PHP would refuse in the written enum. Labels are the names as words: `InTransit` and
`IN_TRANSIT` both read `In transit`.
