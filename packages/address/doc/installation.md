# Installation

| Requirement | Version | Why |
|---|---|---|
| PHP | 8.5 or later | The floor the library declares and is tested on |
| `ext-mbstring` | any | Fields measured, capitals and comparisons in any script |
| `symfony/intl` | ^8.2 | Country codes and names |

```sh
composer require phil/address
```

The formats and subdivisions ship with the library, in `data/`.
