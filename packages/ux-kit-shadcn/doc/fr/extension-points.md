# Points d'extension

| Point | Comment |
|---|---|
| Le balisage d'une recette | Une fois installé, le composant est du code de l'application : changez ses utilitaires dans `templates/components/` |
| La racine d'un composant | Tout attribut donné au composant va sur sa racine ; un `class` s'ajoute à ses utilitaires |
| L'apparence | Les jetons du kit Shadcn, définis dans la feuille de style de l'application |
| Le minutage du titre | Les propriétés `pause`, `duration` et `loop` ; le texte du bouton, `pauseLabel` et `playLabel` |
| Le choix de l'illustration | La propriété `seed` |
| Le contenu de la page « bientôt » | Le bloc `content` |
